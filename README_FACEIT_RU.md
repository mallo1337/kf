# FACEIT-переделка — первая версия

## Что сохранено
- Исходные `main.py` и `database.py` оставлены основой проекта.
- Существующие регистрация, профиль, Premium, статистика, обработка скриншотов и админ-функции сохранены.
- Новая логика добавлена прямо в `main.py` и `database.py`, без разбиения на модули.

## Что добавлено
- Две постоянные автоматические очереди: 2×2 и 5×5.
- Подтверждение участия перед постановкой в очередь.
- Запрет повторной постановки игрока в активную очередь/матч.
- Автоматическое открытие следующей очереди после заполнения предыдущей.
- Выбор капитанов: Premium в приоритете, затем KD и ELO.
- Инлайн-пики капитанов с никнеймом, KD и ELO.
- Тема в группе модераторов `🎮 Матч #ID` после заполнения лобби.
- Итоговое сообщение с картой, игровыми ID, ELO и копируемыми Telegram ID.
- Карты вынесены в отдельный список в `main.py`.

## Запуск
1. Используйте Python 3.10+.
2. Установите зависимости: `pip install -r requirements.txt`.
3. Создайте `.env` на основе собственных актуальных значений (не используйте чужие токены из архивов).
4. Проверьте, что `DATABASE_URL` указывает на PostgreSQL, а `BOT_TOKEN` — на токен вашего бота.
5. Укажите `MODERATOR_GROUP_ID` для супергруппы с включёнными темами (forum topics).
6. Запустите `python main.py`.

При первом старте PostgreSQL автоматически создаст таблицы автоматических матчей. Старые таблицы не удаляются.

## Важные ограничения первой версии
- Сейчас карта выбирается случайно из `AUTO_MAPS`; точный актуальный пул карт нужно подтвердить перед релизом.
- Капитаны выбираются по приоритету Premium, затем KD и ELO. При двух Premium-игроках они получат капитанство по рейтингу KD/ELO.
- Подтверждение результата и начисление ELO именно для новых автоматических матчей ещё нужно связать с существующим потоком скриншотов/модерации отдельным шагом.
- Очереди и пики хранятся в PostgreSQL, но отдельный стресс-тест одновременных нажатий ещё не выполнен.
